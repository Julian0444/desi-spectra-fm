# Documentation

Start with the repository [README](../README.md), then the [canonical evaluation](EVALUATION.md)
and [architecture decisions](DECISIONS.md).

| Material | Purpose |
|---|---|
| `EVALUATION.md` in FM | Canonical results, protocols, limitations and evaluation status. |
| `DECISIONS.md` | Current architecture, recorded alternatives and boundaries. |
| `RELEASE_0_3_0.md` | Release notes, delivery boundaries and evaluated/release identity references. |
| `BATCH_5C_REPRODUCE.md` | Installed-package commands and asset requirements; Spanish technical record. |
| `BATCH_5C_REPORT.md`, `BATCH_5C_REMAINING.md` | Current closure state and remaining work, retaining the economic closure history. |
| `BATCH_5C_AI_REVIEW.md`, `review/` | Semantic procedure, instructions and annotation contract. |
| `BATCH_5C_HUMAN_ACTIONS.md` | H-18, adjudication, independent backup and publication actions. |
| `BATCH_*`, `plan/`, `evidence/` | Technical history of the process, primarily in Spanish. These are not a substitute for the current evaluation overview. |
| `protocol/`, `BATCH_5B_PROTOCOL.md` | Registered protocol and additions; earlier versions and frozen evidence remain preserved. |

Files stay in their existing locations. Historical reports can describe a state
that later changed; dated closure updates distinguish the current state. Frozen
manifests, identities and canonical evidence retain their original bytes and may
contain historical local paths. Editable public prose uses neutral placeholders.
The consensus is a private record, not a public documentation dependency.

Development and audits used AI assistants (Codex and Claude); decisions and
verifications are recorded here. Personal authorship explanations are not
inferred from those records.
